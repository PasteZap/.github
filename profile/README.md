# PasteZap

Free browser tools for PDFs, images, text, data, calculators and planning: 800 tools in 28 categories, 11 languages.

**Website:** https://pastezap.com · **All categories:** https://pastezap.com/categories/

## How it works

- Most tools run entirely in your browser: JavaScript, Web APIs and WebAssembly engines are served from pastezap.com itself, with no CDN fallback.
- Files are not uploaded to an application server. Three tools use the network and say so on their page: Currency Exchange, Internet Speed Test and the optional online voices of Text to Speech.
- No account and no sign-up.
- Navigation, tool names and descriptions are available in 11 languages (en, fr, ar, es, de, pt, it, nl, hi, zh, ja). Technical controls are in English.

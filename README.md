# PasteZap

Free browser tools for PDFs, images, text, data, calculators and planning — about 800 tools in 11 languages.

**Website:** https://pastezap.com

## How it works

- Most tools run entirely in your browser: JavaScript, Web APIs and WebAssembly engines are served from pastezap.com itself, with no CDN fallback.
- Files are not uploaded to an application server. Three tools use the network and say so on their page: Currency Exchange, Internet Speed Test and the optional online voices of Text to Speech.
- No account and no sign-up.

## Built with open-source software

PasteZap relies on projects such as pdf.js, pdf-lib, Tesseract.js, qpdf, HarfBuzz, ImageMagick (magick-wasm), Pyodide, PGlite, Typst and miniPaint. Licence notices are published with each tool.
